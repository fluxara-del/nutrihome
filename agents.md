## Quality Assurance

After implementing a feature:
- Run unit and integration tests.
- Run TypeScript checks and production build.
- Run browser E2E tests.
- Review affected pages at desktop and mobile widths.
- Check light and dark themes.
- Test validation and error states.
- Verify existing data is preserved.
- Add regression tests for fixed bugs.
- Report tests that could not be executed.
- Never merge changes with unresolved critical issues.
